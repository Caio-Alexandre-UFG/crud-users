# 👥 Gerenciamento de Usuários

Aplicativo Android desenvolvido com **Kotlin** e **Jetpack Compose** para gerenciar uma lista de usuários de forma prática, moderna e eficiente. Ideal como projeto de aprendizado com arquitetura limpa e UI responsiva.

## ✨ Funcionalidades

- ✅ Listagem de usuários
- ➕ Adicionar novos usuários
- ✏️ Editar dados de usuários existentes
- 🗑️ Excluir usuários
- 💡 Interface moderna com Material 3
- ⚙️ Arquitetura MVVM com separação em camadas (Domain, Data, Presentation)

## 🛠️ Tecnologias Utilizadas

- [Kotlin](https://kotlinlang.org/)
- [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Material 3](https://m3.material.io/)
- [ViewModel](https://developer.android.com/topic/libraries/architecture/viewmodel)
- [StateFlow](https://developer.android.com/kotlin/flow/stateflow-and-sharedflow)
